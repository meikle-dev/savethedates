# Google Ads (Search, Performance Max and YouTube)

Start with **Search ads**. People searching "wedding website" or "digital save the date" already want the product, so it's the cheapest place to find customers. Add Performance Max or YouTube later, once Search shows what works.

## What's here

| Folder | Use |
| --- | --- |
| `display-images/landscape-1200x628/` | Landscape images (1.91:1) |
| `display-images/square-1200x1200/` | Square images (1:1) |
| `display-images/portrait-960x1200/` | Portrait images (4:5) |
| `logos/` | Square logo 1200×1200, landscape logo 1200×300 (navy and white versions) |
| `youtube/` | Launch film (16:9), 10-second vertical ad (for Shorts), film thumbnail 1280×720 |

The display images have **no text on them, on purpose**. Google recommends image-only pictures and supplies the text from the headlines below.

## 1. Search campaign (start here)

- **Goal:** Website traffic, or Leads once conversion tracking exists.
- **Locations:** United Kingdom and Ireland. Choose "Presence: people in or regularly in".
- **Budget:** start around £5–10 a day and review after two weeks.
- **Final URL:** `https://savethedates.co.uk`. Keep auto-tagging on.

**Keywords (phrase match):** `"wedding website"`, `"wedding website uk"`, `"digital save the date"`, `"online save the date"`, `"e save the date"`, `"wedding rsvp website"`, `"online wedding rsvp"`, `"wedding website builder"`

## 2. Performance Max (after a few weeks of Search)

Upload these into one asset group:
- **Images:** all of `display-images/`
- **Logos:** `logos/logo-square-1200x1200.png` and `logos/logo-landscape-1200x300.png`
- **Videos:** upload the two videos in `youtube/` to the YouTube channel (they can be unlisted), then select them
- **Headlines:** 5 from the list above
- **Long headline:** `Your Save the Date, invitation, details and RSVPs on one private wedding website`
- **Descriptions:** the four above
- **Business name:** `SaveTheDates`

## 3. YouTube

- Upload `youtube/savethedates-launch-film-1080p.mp4` to the channel with `launch-film-thumbnail-1280x720.jpg` as the thumbnail. It can also run as a skippable in-stream ad.
- Upload `youtube/savethedates-ad-9x16-10s.mp4` as a **Short**.
