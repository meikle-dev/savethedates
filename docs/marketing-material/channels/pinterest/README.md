# Pinterest

Couples plan weddings on Pinterest, and pins keep getting found for months, so this is likely the best free channel. All pins are 1000×1500 (2:3), Pinterest's recommended size.

## What's here

| Folder | Use |
| --- | --- |
| `pins/designs/` | One pin per design (12) |
| `pins/topics/` | 6 pins: hero, twelve designs, RSVPs, save the date first, sharing, price |
| `video-pins/` | The 10-second vertical video and its cover |
| `profile/` | Profile picture |

## Set up

1. Create a **free business account** and use `profile/profile-picture-1080.png` as the picture.
2. **Claim the website** (Settings → Claimed accounts). Choose the **DNS TXT** option and add the record at the domain registrar; this needs no change to the site. Claimed sites get attribution and analytics.
3. Create three boards:
   - **Wedding website designs**: the 12 design pins
   - **Digital save the dates**: hero, save the date first and sharing pins
   - **Wedding RSVPs and planning**: RSVP and price pins

## Pinning

Spread pins out over two to three weeks (one or two a day) rather than posting everything at once.

**Design pins:** link each one to its own example page. Use this pattern for the title, description and link:

| | |
| --- | --- |
| **Title** | `Velvet wedding website design: Save the Date, invitation and RSVP` |
| **Description** | `Claret velvet, blush paper and gold ribbon. A matching Save the Date, Invitation, Details and RSVP page, all in one design. Try it free with your own words and photo; £39 once to publish. Example wedding with fictional names.` |
| **Link** | `https://savethedates.co.uk/examples/velvet` |

Link slugs: `minimal`, `romantic`, `bold`, `terracotta`, `heather`, `coastal`, `riviera`, `alcantara`, `countryside`, `velvet`, `black-tie`, `evening-gold`. Each description should start with the design's official line from the [features guide](../../marketing-context/marketing-docs/app-features-and-screenshots-guide.md#31-twelve-designs-one-look-from-start-to-finish-lead-feature).

Pinterest ads can promote the best-performing pins. Wait until organic pins show which designs get saved most.
