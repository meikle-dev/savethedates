## Stories

Post the six Stories in order. On the last Story (or any of them), add a **link sticker** to `https://savethedates.co.uk` and place it just above the SaveTheDates line at the bottom. Save them as a Highlight called "Designs" or "How it works".

## Reels

The Reel has original music, so it's safe to post from a business account. If you'd rather use a sound from Instagram's library, upload `-no-music.mp4` and add the sound in the app. Business accounts can only use sounds marked for commercial use.

Instagram and Facebook ads are set up together in Meta Ads Manager. Read the [setup guide](../../marketing-setup-guide.md) first, especially the measuring section.

| Placement | Upload |

Put the 9:16 and 4:5 versions in the same ad, so each placement gets the right shape.
