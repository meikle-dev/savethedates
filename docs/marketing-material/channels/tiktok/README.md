# TikTok

## What's here

| Folder | Use |
| --- | --- |
| `videos/` | The 10-second vertical video (1080×1920), with music and without, and a cover image |
| `profile/` | Profile picture |

## Set up

1. Create a **Business account**. Use `profile/profile-picture-1080.png` as the picture and `https://savethedates.co.uk` as the website.
2. **Bio:** `Your wedding website, beautifully done. Save the Date, invitation, details & RSVPs. £39 once.`

## Posting

- **With our music:** upload `videos/savethedates-ad-9x16-10s.mp4`. The music is original, so it's safe for a business account.
- **With a TikTok sound:** upload `-no-music.mp4` and add a sound from the **Commercial Music Library**. Business accounts can't use other trending sounds.
- **Cover:** `videos/savethedates-ad-9x16-10s-cover.jpg`
- **Caption:** `Your wedding website, beautifully done 🤍 Twelve designs, RSVPs with meal choices, £39 once. #weddingwebsite #savethedate #weddingplanning #weddingtok #ukwedding`

TikTok rewards a regular stream of native, casual videos. This polished clip is a good first post. After that, screen recordings of the real product (flicking through designs, filling in an RSVP) will usually do better than more polished ads.

## Paid (later)

TikTok Ads Manager can promote the same video. Start once Meta and Google show which messages work.
